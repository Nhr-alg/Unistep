Derivatives of polynomials

The power rule differentiates each term independently: the exponent moves down as a multiplier and decreases by one. Constants vanish because their rate of change is zero.

Find the derivative of 3x^3 + 2x^2 - 5x + 1

Answer 9x^2 + 4x − 5

  1. Identify the Function Write the expression in the standard polynomial form so each power of x can be handled separately. f(x) = 3x^3 + 2x^2 − 5x + 1
  2. Apply the Power Rule For every term axⁿ, the derivative is n·a·xⁿ⁻¹. Constants (n = 0) drop out. d/dx (a·xⁿ) = n·a·xⁿ⁻¹
  3. Differentiate Term by Term 3x^3 → 9x^2; 2x^2 → 4x; -5x^1 → −5; 1 → 0 9x^2 + 4x^1 − 5x^0
  4. Final Answer Combine the differentiated terms into a single expression. f′(x) = 9x^2 + 4x − 5

Assumptions: Polynomial in a single variable; Differentiated with respect to x
