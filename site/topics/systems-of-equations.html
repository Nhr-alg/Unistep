Systems of two equations

Two linear equations describe two lines. Their intersection is the single point satisfying both. Cramer’s rule finds it directly through the determinant of the coefficient matrix.

Solve the system 2x + 3y = 8, x - y = 1

Answer x = 2.2, y = 1.2

  1. Write the System Put both equations in the form ax + by = c so the coefficients can be compared directly. 2x + 3y = 8; 1x − 1y = 1
  2. Compute the Determinant The determinant of the coefficient matrix must be non-zero for a unique solution. D = (2)(-1) − (1)(3) = -5
  3. Apply Cramer's Rule Replace one column at a time with the constants to solve for each variable. x = Dx/D = 2.2; y = Dy/D = 1.2
  4. Final Answer Both equations are satisfied at this single point. x = 2.2, y = 1.2

Assumptions: Two equations in two unknowns; Determinant is non-zero
