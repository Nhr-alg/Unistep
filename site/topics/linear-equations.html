Linear equations

A linear equation describes a straight line and has exactly one solution. Isolating x reverses each operation in turn: remove the constant, then divide by the coefficient.

Solve 3x - 7 = 11

Answer x = 6

  1. Write the Equation Put the equation in the standard form ax + b = c. 3x − 7 = 11
  2. Move the Constant Subtract -7 from both sides. 3x = 11 − (-7) = 18
  3. Divide by the Coefficient Divide both sides by 3. x = 18 / 3 = 6
  4. Check Substituting the answer back into the original equation reproduces the right-hand side. 3(6) − 7 = 11

Assumptions: Single variable; a ≠ 0

Solve 5x + 2 = -13

Answer x = -3

  1. Write the Equation Put the equation in the standard form ax + b = c. 5x + 2 = -13
  2. Move the Constant Subtract 2 from both sides. 5x = -13 − (2) = -15
  3. Divide by the Coefficient Divide both sides by 5. x = -15 / 5 = -3
  4. Check Substituting the answer back into the original equation reproduces the right-hand side. 5(-3) + 2 = -13

Assumptions: Single variable; a ≠ 0
